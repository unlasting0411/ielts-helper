# 雅思学习助手

一个月备考雅思学术类的个人学习助手（PWA）：每日计划、打开本地资料、考试计时、分数记录、错题和同义替换整理。

- App 本身不含任何题目、解析或讲义；资料由使用者在手机上导入，只保存在本机浏览器（IndexedDB），不上传、不联网。
- 运行时零网络请求：所有静态资源（含 pdf.js、字体映射）由 Service Worker 预缓存，断网可用。

## 第二版新增

- **答题卡与自动判分**：听力、阅读在手机上填 40 个答案，交卷自动判分、换算分数。错题选错因后一键记入错题本（出处自动生成），答对数一键写入分数页（同一天同一套题的听力和阅读合并成一条）。每套题的答案由使用者从自己的资料录入一次（可整段粘贴），只存本机。入口：今日任务“开始”后阅读器的下半屏、未导入文件时的“答题卡”、阅读器右上角“下半屏”。
- **练习页（原“计时”）**：分 计时 / 口语 / 写作 三栏。
  - 口语：录音存本机，可回放、分享、写备注；Part 2 准备 1 分钟后自动录 2 分钟并自动停止。
  - 写作：编辑器带字数统计和计时，一键复制“批改请求 + 题目 + 作文”给 Claude；记录批改分数和要点；“重写一篇”时可展开上一版对照。
- **按分数调整**：
  - 第 1 天摸底、第 14 天检查点按录入的分数自动判断。
  - 今日页“当前重点”显示各科离目标的差距（最近两次平均）、本周最多错因的练法、按最弱一科推荐还没做过的备用题。
  - 3 小时版写作/口语按弱项分配。
  - 设置里可改各科目标分，可关闭“按分数调整”。

## 开发

```bash
npm install
npm run dev        # 本地开发（--host，可用手机同一 Wi-Fi 访问，但非 HTTPS 时无法安装）
npm test           # 单元测试（计划、分数换算、文件名识别、文件匹配、计时、笔记、导出导入）
npm run build      # 类型检查 + 构建到 dist/
npm run preview    # 预览构建产物（含 Service Worker）
```

测试用的空白 PDF 和音频：`node scripts/make-test-assets.mjs`（加 `--big` 再生成 40 MB 的 PDF），输出到 `test-assets/`，已在 `.gitignore` 中，不会进入仓库和构建产物。

## 部署与安装

PWA 只有在 HTTPS 或 localhost 下才能“安装”。推荐 GitHub Pages：

1. 新建 GitHub 仓库，推送本项目到 `main` 分支。
2. 仓库 Settings → Pages → Source 选 “GitHub Actions”。`.github/workflows/deploy.yml` 会自动测试、构建并发布。
3. 安卓 Chrome 打开发布的网址 → 右上角菜单 → “添加到主屏幕”。

`base` 设为 `./`，部署在子路径（如 `https://<用户名>.github.io/ielts-helper/`）也能用。Cloudflare Pages、Netlify 同理：构建命令 `npm run build`，输出目录 `dist`。

```
  db.ts                 IndexedDB（idb），7 个 store；导出 / 导入 / 清空
  lib/plan.ts           第几天、3 小时版改写规则、每天追加单词卡片
  lib/score.ts          答对数 → 分数、总和、总分
  lib/tagger.ts         文件名 → 标签
  lib/matcher.ts        今日任务 → 本地文件（精确 → 单套全科 → 整本书 + 书签 → 未导入）
  lib/timer.ts          基于时间戳的计时器（纯函数，可测试）
  lib/notes.ts          错因周统计、词对复习队列
  timerStore.ts         全局计时：震动 + 提示音 + 屏幕提示、Wake Lock、后台恢复
  pages/                今日 / 资料库 / 阅读器 / 计时 / 分数 / 笔记 / 设置
  components/           PDF 阅读器、音频播放器、手写 SVG 图表
scripts/                pdf.js 资源复制、图标生成、测试素材生成
```

## 实现时做的假设

交接文档要求“没写清楚的地方选更简单的实现，并记下假设”，以下是这些地方：

1. **文件名规则放宽**：文档里 `C`、`T`、`S` 三条正则以 `\b` 结尾，`C17T3S4.mp3` 这类紧凑命名识别不到。改为“数字后面不再跟数字”，其余规则不变。
2. **音频类别**：所有音频文件都归为“音频”类别（文档只规定识别到册号时如此）；没识别到册号的仍显示在“未分类”。
3. **“未分类”**指没识别到剑桥册号的文件。
4. **PDF 没写科目时** skill 设为 `all`（整本书或单套全科）。
5. **本周**：计划内按计划的第 N 周（第 1–7、8–14、15–21、22–28 天）；计划外按自然周（周一到周日）。错因周统计按错题的录入时间落在哪一周计算。
6. **3 小时版**：
   - 阅读、听力的改写只用于练习日（`practice`）和第 3 周被取消的模考日；复盘日、调整期的阅读听力保持原文。
   - 写作、口语单双数天交替适用于所有非模考日。
   - 第 3 周只在第 15、19 天模考；第 17 天按练习显示，去掉“模考：”前缀和模考连续计时。
7. **分数页**：四科都填写才显示总分和“离总和 29 还差 X 分”；只填部分时显示已填科目合计。
8. **计时结束询问录入分数**：听力 30 分钟、阅读 60 分钟和模考连续三种预设结束时询问。
9. **从后台回来时积压多个提醒**：全部标记为已提醒，但只响最近的一个，避免连响。
10. **计时状态**存在 localStorage（几十字节），不属于“大数据”；其余数据都在 IndexedDB。
11. **重复导入**（同名同大小）：确认列表里标“已导入，是否覆盖”，默认不覆盖；覆盖时保留原有书签。
12. **大 PDF**：32 MB 以下整块读入；更大的文件按 pdf.js 请求的范围从 Blob 分段读取，避免一次占用几百 MB 内存。
13. **导入数据**按 id 覆盖、其余保留（不会先清空）。
14. **返回键**：“今日”是主界面，其他页面（资料、计时、分数、笔记、设置、阅读器）都是它的子页面。历史记录最多两层，所以手机返回键和页面左上角返回按钮都回到今日，在今日再按返回退出 App；子页面之间切换、今日里切换天数都不增加历史层。
15. **答案写法**：多个可接受写法用 `/` 分隔；括号内为可省略的词；两题顺序不限写成 `B&D`（两题都写）。判分时忽略大小写、首尾标点和多余空格，T/F/NG、Y/N/NG 缩写和全称等价；其余要求完全一致（拼写错算错，和考试一致）。
16. **底部导航“计时”改名“练习”**，计时功能原样保留在第一栏。
17. **口语录音不做自动转文字**：浏览器的语音识别会把录音发到外部服务器，违背“不上传、不联网”，所以只提供分享，由使用者自己选转写工具。
18. **当前水平**取每科最近两次成绩的平均；默认目标 8 / 8 / 6.5 / 6.5（总和 29）。
19. **摸底判断阈值**（离 29 差 ≤1.5 / ≤3 / >3）和各错因的练法是经验建议，不是官方规则。
20. **3 小时版按弱项分配**：写作、口语离目标的差距相差 ≥ 0.5 时，弱的一科每 3 天练 2 天；否则单双数天交替。
21. **备份**新增答案、答题记录和作文；口语录音和导入文件一样不进备份。
